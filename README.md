# ✈️ LSTM Time Series Forecasting - Air Passengers Dataset

This project implements a **time series forecasting model** using **Long Short-Term Memory (LSTM)** neural networks on the famous **Air Passengers dataset**. The dataset contains monthly totals of international airline passengers from **January 1949 to December 1960**.

## 📊 Dataset

- **Source**: AirPassengers.csv
- **Columns**:
  - `Month`: Date in YYYY-MM format
  - `Passengers`: Number of passengers

## 🧠 Model Description

- **Model Used**: LSTM (Long Short-Term Memory) - a type of Recurrent Neural Network (RNN)
- **Input Features**: Past 12 months of passenger data
- **Target**: Predict the number of passengers in the next month
